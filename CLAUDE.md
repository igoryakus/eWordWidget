# eWordWidget

Нативный мультиплатформенный (macOS Tahoe + iOS) виджет на SwiftUI/WidgetKit, который каждые 10 минут показывает английское слово для запоминания.

## Возможности
- Слово, британская транскрипция (IPA), часть речи, перевод на русский.
- Уровни A1–C2, 6873 слова: A1–C1 по списку Oxford 5000, C2 — продвинутая лексика вне его. Слово есть только на одном уровне: каждый уровень дополняет предыдущие.
- 3 примера с переводом (изучаемое слово подсвечивается) и 0–3 идиомы; в виджете перевод идёт через тире, примеров и идиом показывается столько, сколько влезает.
- Прогресс (запомненные слова) и выбранный уровень хранятся в App Group. Запомненные слова больше не показываются; когда запомнен весь уровень, он показывается по кругу.
- Режим задания EN/RU: EN — показано английское слово, перевод размыт; RU — показано русское слово, английское (и транскрипция) размыто. Нажатие на размытое открывает ответ (и переводы примеров/идиом), повторное — скрывает; для следующего слова ответ снова скрыт. Состояние `direction`/`revealed` в state.json.
- Кнопки на виджете (App Intents) по порядку: EN/RU, уровень, ✓ запомнил с процентом, → следующее слово. 🔊 — под «следующим», у правого края (в medium — в строке «Примеры»). В small и medium — компактные круги 22 pt.
- Озвучка только записями словарей: Oxford Learner's / Cambridge / Free Dictionary (опрашиваются параллельно, берётся первый ответ; Cambridge и Free Dictionary могут не работать через некоторые VPN, например Сингапур). Системного голоса нет: если записи нет — ничего не играет, подпись «нет записи». Звук из кэша, иначе скачивается и играет. Виджет заранее качает звук для ближайших 3 слов. Кэш — `Library/Caches/Pronunciations` в контейнере App Group, источник в имени файла. Последняя озвучка (`lastAudio.json`: словарь, слово, UK/US) показывается серой подписью «Oxford · UK» слева от кнопки 🔊.
- Размеры: small / medium / large. Приложение-контейнер показывает текущее слово, кнопку «Запомнил», выбор уровня, прогресс со сбросом и переключатель акцента UK/US.

## Структура
- `Shared/` — общий код для обоих таргетов (синхронизированная папка, добавлена в pbxproj вручную):
  - `Word.swift` — модели `Word`, `Example`, `Idiom`, `Level`, `Accent`; `WordStore` (App Group, интервал 10 мин, сдвиг, уровень, запомненные слова, детерминированный порядок слов уровня).
  - `WordBank.swift` — загрузка баз из JSON (лениво, по уровню).
  - `Words/a1.json` … `c2.json` — базы слов, одно слово на строку: {w, ipa, pos, tr, ex: [[англ, рус]×3], id: [[фраза, значение]]}. Слово не должно повторяться на других уровнях; в каждом примере должна быть форма, начинающаяся с самого слова (для подсветки).
- `docs/words-report.md` — отчёт по базам.
  - `Pronouncer.swift` — воспроизведение + `AudioSource` (источники звука, кэш).
  - `Intents.swift` — `SpeakWordIntent` (AudioPlaybackIntent, выполняется в процессе приложения).
  - `Highlight.swift` — подсветка слова в примерах.
- `WordWidgetExtension/WidgetIntents.swift` — `NextWordIntent`, `LearnWordIntent`, `NextLevelIntent`. Только в расширении, чтобы выполнялись в процессе виджета без запуска приложения (иначе задержка в несколько секунд).
- Состояние (уровень, сдвиг, запомненные) — файл `state.json` в контейнере App Group, не UserDefaults (кэш между процессами давал устаревшие значения).
- `WordWidgetExtension/` — виджет `EWordWidget` (таймлайн на 2 часа, запись на каждую смену слова). Таймерные ProgressView(timerInterval:) и подобные анимации в виджете не использовать: Центр уведомлений на macOS перерисовывает весь виджет каждый кадр, CPU растёт до 50–80% (так было с кольцом таймера, его убрали).
- `eWordWidget/` — приложение (`ContentView`).

## Настройки
- Bundle ID: `com.yakus.eWordWidget`, расширение `com.yakus.eWordWidget.WordWidgetExtension`.
- App Group: `group.com.yakus.ewordwidget` (оба таргета).
- Sandbox + Outgoing Connections включены в обоих таргетах.
- Deployment target 26.5. В таргете приложения `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`, в расширении — нет; поэтому общие типы помечены `nonisolated`, а `Pronouncer` — `@MainActor`.
- Подпись: Personal Team (бесплатный Apple ID).

## Статус
- Собирается через xcodebuild для macOS и iOS Simulator. На реальном виджете ещё не проверялся.
